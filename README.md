# DevOps-beadando

Egyszerű Node.js alapú HTTP szerver, amely egy "Hello DevOps" üzenetet ad vissza.

## Előfeltételek

- Node.js (>= 18)
- npm

## Build

A projektnek nincs külön fordítási lépése, csak a függőségek telepítése szükséges. A parancssorba írja be az alábbiakat.

```bash
npm install
npm run build
