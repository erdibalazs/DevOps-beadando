# DevOps-beadando

Egyszerű Node.js alapú HTTP szerver, amely egy "Hello DevOps WORLD 2.0!" üzenetet, és a szerver pontos idejét adja vissza.

## Előfeltételek

- Node.js (>= 18)
- npm

## Build

A projektnek nincs külön fordítási lépése, csak a függőségek telepítése szükséges.

```bash
npm install
npm run build
